The ``matrix_divided`` function
===============================

Import the function:

    >>> matrix_divided = __import__("2-matrix_divided").matrix_divided

Divide a matrix of integers:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 2)
    [[0.5, 1.0, 1.5], [2.0, 2.5, 3.0]]

Divide a matrix of floats:

    >>> matrix = [[1.5, 2.5], [3.5, 4.5]]
    >>> matrix_divided(matrix, 2)
    [[0.75, 1.25], [1.75, 2.25]]

Original matrix is unchanged:

    >>> matrix = [[1, 2], [3, 4]]
    >>> new = matrix_divided(matrix, 2)
    >>> matrix
    [[1, 2], [3, 4]]

Round to 2 decimal places:

    >>> matrix_divided([[1, 2], [3, 4]], 3)
    [[0.33, 0.67], [1.0, 1.33]]

Divide by float:

    >>> matrix_divided([[2, 4], [6, 8]], 2.0)
    [[1.0, 2.0], [3.0, 4.0]]

Divide by infinity:
